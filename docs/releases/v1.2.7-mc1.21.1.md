# Dwurdy Sharks 1.2.7 — Minecraft 1.21.1

Dwurdy Sharks 1.2.7 is a community maintenance release for the NeoForge
1.21.1 target. It keeps the `benssharks` mod id so it can replace Ben's Sharks
1.2.6 in an existing world after a backup.

## Fixed

- Wild large sharks are no longer made permanently persistent by ordinary
  interaction paths.
- Tamed sharks remain persistent.
- A failed taming attempt does not permanently pin a wild shark.

## Included

- The credited Ben's Sharks content roster, items, armor, plush, food, sounds,
  and GeckoLib assets.
- Public branding, CurseForge copy, migration notes, and version-branch
  policy for the maintained fork.

## Verification

- `gradlew.bat clean build` passes on Java 21 with NeoForge 21.1.248.
- GeckoLib 4.x is declared as a required runtime dependency.
- The in-game wild-versus-tamed regression checklist is documented in
  [`docs/TESTING.md`](../TESTING.md).

This release is for Minecraft 1.21.1 + NeoForge only. Other Minecraft versions
and loaders require separate ports and verification.
